# 🎂 Birthday Surprise Website 🎉

An interactive birthday surprise website with animated transitions, confetti effects, and a personalized message!

## ✨ Features

- 🔐 **Login Screen** - Birthday photo with passcode protection
- ⏳ **Loading Animation** - Smooth loading screen with spinner
- 🎬 **Smooth Transitions** - Beautiful fade and slide animations
- 🎂 **Animated Cake** - Interactive 3D cake with flickering candle
- 🎉 **Confetti & Particles** - Continuous falling confetti and floating emoji
- 💌 **Personalized Message** - Customizable birthday greeting

## 🚀 How to Use

1. **Clone or download** this repository
2. **Open `index.html`** in your web browser
3. **Enter the passcode** (default: `1234`)
4. **Enjoy the celebration!**

## ⚙️ Customization

Edit the configuration in `index.html` (around line 187):

```javascript
const CORRECT_PASSCODE = "1234";  // Change passcode
const BIRTHDAY_NAME = "You";      // Birthday person's name
const CUSTOM_MESSAGE = "Wishing you a day filled with joy..."; // Custom message
```

### Change the Birthday Photo

Find this line and replace the URL:
```html
<img src="https://images.unsplash.com/photo-1559827260-dc66d52bef19?w=400&h=400&fit=crop" alt="Birthday Person" class="login-photo">
```
